ABC FITNESS STUDIO — HTML WEBSITE

FILES
- index.html: Home page
- gallery.html: Product gallery and demonstration shopping cart
- about.html: Business information and contact form
- community.html: Community page

HOW TO OPEN
1. Extract the ZIP file.
2. Keep the four HTML files together in the same folder.
3. Open index.html in a browser.

IMPORTANT STORAGE LIMITATION
This is a static HTML website. It uses browser sessionStorage for the demonstration cart
and localStorage for contact messages and email subscriptions. These records stay in the
visitor's browser and are not sent to a server.

A static .html-only website cannot directly write information to a MySQL database.
Real shared storage requires a server-side component such as PHP, a database API, or
another backend service. This version does not collect payments or submit real orders.

ACCESSIBILITY AND RESPONSIVE DESIGN
- Semantic HTML landmarks and headings
- Skip link and keyboard-visible focus indicators
- Explicit form labels and built-in browser validation
- High-contrast text and button colors
- Responsive layouts for desktop, tablet, and mobile screens
- Content centered with a maximum width
